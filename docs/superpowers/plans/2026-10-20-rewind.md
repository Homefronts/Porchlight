# Rewind Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A quarterly, Wrapped-style recap of the user's own listening, logged and built entirely on-device, with an optional Google Takeout import for the current quarter.

**Architecture:** Pure logic (quarters, play timing, rewind building, Takeout parsing, palette) lives in `src/lib/rewind/` with unit tests. A small IndexedDB-backed log (`idb-keyval`, its own store) holds raw plays for the open quarter and sealed rewinds. One hook mounted in AppShell logs plays (one write per track); an idle-time scheduler seals ended quarters. UI is a `/rewind` route plus a full-screen story player.

**Tech Stack:** React 19, TypeScript, zustand, TanStack Router (file routes), `idb-keyval`, `motion`, vitest; Tauri 2 (`tauri-plugin-dialog` already in Cargo, `@tauri-apps/plugin-http` already used). New npm deps: `fflate` (Takeout .zip) and `html-to-image` (save slide as PNG).

**Spec:** `docs/superpowers/specs/2026-10-20-rewind-design.md`

## Global Constraints

- Nothing leaves the device except capped metadata lookups for top-list tracks (spec).
- Raw plays only for the open quarter; sealed rewinds are frozen snapshots.
- A play counts at min(half the length, 240 s), never under 30 s (same as `src/lib/lastfm-scrobbler.ts`).
- Calendar quarters, local time. Rewind available the day after its quarter ends.
- One history per install; not split by account.
- Performance: no new per-second timer, one IndexedDB write per track, building 5,000 plays < 200 ms, Takeout parse off the UI thread, only current + next slide mounted, `transform`/`opacity` animations only.
- With AI music off at build time, confirmed AI (`isAiBlocked`) is excluded; plays with `aiAllowed` count.
- History switch pauses logging only; "Clear listening history" also deletes saved rewinds.
- Look: big type, tilted (~8°) most-played cover cropped off the right edge, background gradient + accent from the cover, light grain. Reference: `.superpowers/brainstorm/*/content/rewind-style-v6.html` (main checkout, local only).
- vitest only picks up `src/**/*.test.ts`; DOM tests need `// @vitest-environment jsdom` and `createElement` (no JSX in tests); stub `localStorage` with `vi.hoisted` where settings are imported (see `src/lib/ai/use-ai-hooks.test.ts`).
- Line endings: stage with `git -c core.autocrlf=false add`.
- Tools: `node_modules/.bin/vitest`, `node_modules/.bin/tsc` (no pnpm on PATH). The worktree has no `node_modules`: before Task 1, link the main checkout's with a junction (`cmd //c mklink /J node_modules ..\\..\\node_modules`). New deps (Task 6/8) need a package manager: ask the user to run `! pnpm add fflate html-to-image` in the worktree, then re-link if needed.

## Review Focus

1. Quarter boundaries across time zones / DST: a play at 23:59 on 31 Mar local belongs to Q1.
2. Repeat-one: the same video replayed back-to-back must log a second play (the scrobbler's known gap must not be copied).
3. Takeout re-import of the same file, and Takeout entries overlapping plays YTubic logged itself, must not double-count.
4. App closed mid-track: a track already past the bar must still be logged (flush on `pagehide`/unload).
5. A rewind with missing covers or metadata (imported plays) still renders every slide.

### Task 3: Build a rewind (pure, fast)

**Files:**
- Create: `src/lib/rewind/build.ts`
- Test: `src/lib/rewind/build.test.ts`

**Interfaces:**
- Consumes: `Play` (Task 2), `QuarterId` (Task 1).
- Produces:
  ```ts
  type Ranked = { key: string; name: string; plays: number; minutes: number; thumb?: string; topAlbum?: { id?: string; name: string; thumb?: string } };
  type Rewind = { quarter: QuarterId; builtAt: number; minutes: number; plays: number;
    topArtists: Ranked[]; topSongs: Ranked[]; topAlbums: Ranked[];   // 5 each
    hours: number[];            // 24 buckets of minutes, local time
    newArtists: Ranked[];       // up to 5, artists with no play in any earlier sealed rewind
    palette?: Record<string, { bg: [string, string, string]; accent: string }> }; // keyed by thumb URL, filled in Task 5
  function buildRewind(q: QuarterId, plays: Play[], opts: { excludeAi: (p: Play) => boolean; knownArtists: Set<string>; now: number }): Rewind | null;
  const MIN_MINUTES = 60, MIN_SONGS = 10;
  ```
  Artist key = channel id, else normalised name (`normalizeName` from `src/lib/ai/match.ts`). Top lists rank by counted plays, ties by minutes. `minutes` sums `playedSec` of all plays (counted or not). An artist's `topAlbum` is that artist's most-played album in these plays.
