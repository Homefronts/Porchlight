# Docs

Background for anyone working on YTubic Plus. Building and testing are in the main
[README](../README.md#dev).

| Folder | What's in it |
|---|---|
| [`superpowers/specs/`](superpowers/specs/) | Design docs: what a feature does, the decisions behind it and what was left out (offline downloads, the AI music filter, …). Start here before changing a feature. |
| [`superpowers/plans/`](superpowers/plans/) | The step-by-step build plans those features were implemented from. |
| `s/` | The share-link landing page (served by GitHub Pages). Keep it at this path: share links point here. |

Plans and specs were written with AI assistance and reviewed along the way.
